# Suno Studio Guide (2026)

**Purpose:** Guide for using Suno Studio's advanced editing and export features to finish tracks professionally.

**Version:** Suno Studio (January 2026)

---

## What is Suno Studio?

Suno Studio is the advanced editing environment for finishing generated tracks. Instead of regenerating entire songs, you can:

- Edit specific regions (copy, duplicate, delete, crop, heal)
- Control clip behavior (tempo, transpose, speed, volume)
- Add professional fades
- Export loops for social media
- Export multitrack stems for DAW finishing
- Generate MIDI from stems

---

## Core Studio Features

### Region Editing

**Available Actions:**
- **Copy** - Duplicate a region to reuse elsewhere
- **Duplicate** - Create an identical copy
- **Delete** - Remove a section
- **Crop** - Trim to specific length
- **Heal** - Smooth transitions between edits

**When to Use:**
- Chorus is perfect → Copy it to use as Final Chorus
- Verse too long → Crop it down
- Weak bridge → Delete and extend from chorus instead
- Abrupt transition → Heal the edit point

### Clip Settings

**Tempo Behavior:**
- **On Beat** - Locks to project tempo (stretches/compresses audio)
- **Original** - Keeps original tempo (may drift)

**Other Controls:**
- **Transpose** - Shift pitch in semitones
- **Speed** - Adjust playback speed
- **Volume** - Control clip level

**When to Use:**
- Exporting to DAW → Set Manual BPM for consistent tempo
- Key mismatch → Transpose up/down
- Section too fast/slow → Adjust speed
- Balance levels → Adjust volume per clip

### Fades

**Adjustable fade in/out on clip edges**

**When to Use:**
- Outro ends abruptly → Add fade out
- Intro starts too harsh → Add fade in
- Smooth region transitions → Add crossfades

## Export Workflows

### Export Options

| Export Type | Use Case |
|-------------|----------|
| **Full Song** | Complete finished track |
| **Selected Time Range** | Social media loops (20-35 sec hooks) |
| **Multitrack (Stems)** | DAW finishing, remixing |

### Export Strategy by Goal

**For Social Media (TikTok/Reels/Shorts):**
1. Identify the hook section (20-35 seconds)
2. Select that time range
3. Export Selected Time Range
4. Clean loop with consistent downbeat

**For DAW Finishing:**
1. Set Manual BPM in Studio (prevents tempo drift)
2. Export Multitrack (stems)
3. Import stems into your DAW at matching tempo
4. Apply EQ, compression, reverb, final mastering

**For Remixing:**
1. Export Multitrack
2. Optionally generate MIDI from stems (paid feature)
3. Use stems + MIDI in your DAW for creative rework

### Individual Clip Export

You can download a single clip (WAV) from the timeline context menu.

**Use for:**
- Extracting just the vocal stem
- Grabbing a specific drum loop
- Isolating one perfect section

## Studio Workflow: From Generation to Finished Track

### Step 1: Generate with Structure in Mind

**In your lyrics, plan for Studio editing:**
- Keep chorus lines short and repeatable (easy to copy/duplicate)
- Write clear section boundaries (easier to crop/delete)
- Keep last lyric line short (room for fade out)
- Avoid instrument sprawl (cleaner stem exports)

**Example:**
```
[Intro]
(short, establishes palette)

[Verse]
(tight lines, clear pocket)

[Chorus]
(simple hook, biggest lift)

[Bridge]
(contrast, space)

[Final Chorus]
(same hook, biggest version)

[Outro]
(short, leave room for fade)
```

### Step 2: Edit Regions

**Common fixes:**
- Chorus perfect? → Copy to Final Chorus position
- Verse too long? → Crop it down
- Bridge weak? → Delete and extend from chorus
- Transition abrupt? → Heal the edit point

### Step 3: Add Fades

- Fade out on outro (smooth ending)
- Fade in on intro (gentle start)
- Crossfades between edited regions (smooth transitions)

### Step 4: Set Tempo (if exporting to DAW)

- Set Manual BPM to match your generation
- Ensures stems import at correct tempo in DAW
- Prevents drift and alignment issues

### Step 5: Export

**Choose export type:**
- Full Song → Finished track for distribution
- Selected Time Range → Social media loop
- Multitrack → DAW finishing

## Advanced: MIDI from Stems

**Feature:** Generate MIDI from a stem (paid action, credit cost applies)

**Workflow:**
1. Export Multitrack
2. Select a stem (melody, bass, etc.)
3. Click "Get MIDI"
4. Import MIDI + stem into DAW
5. Use MIDI to trigger different instruments or edit melody

**Best for:**
- Recreating melodies with different instruments
- Editing note timing/pitch in DAW
- Building remixes with original melodic structure

## Planning for Studio: Tag Strategy

### Top-Load the Palette

**Before your first lyric line, include:**
- 1 mood descriptor
- 1 energy direction
- 1-2 key instruments

**Example:**
```
[Mood: Focused]
[Energy: Medium]
[Instrument: Keys, Drums]

[Intro]
...
```

**Why:** Reduces "random first 10 seconds" and keeps early arrangement consistent.

### Localize Energy Turns

**Place [Energy: High] immediately before the chorus** (not only at the top)

**Example:**
```
[Pre-Chorus]
[Build-Up]
(raise anticipation)

[Chorus]
[Energy: High]
(hook payoff)
```

**Why:** Prevents verses from coming in too hot; makes chorus feel like a lift.

### One Job Per Tag

**Avoid conflicts:**
- ❌ `[Mood: sad, happy, angry]`
- ✅ `[Mood: Melancholic]`

**Why:** Conflicts get averaged and you lose emotional clarity.

### Fewer Instruments = Cleaner Stems

**Pick 2-3 anchor instruments instead of a long list**

**Example:**
- ✅ `[Instrument: Keys, Drums]`
- ❌ `[Instrument: Keys, Drums, Bass, Guitar, Synth, Strings, Brass]`

**Why:** Cleaner arrangement, less clutter, easier multitrack export.

## Common Studio Fixes

| Problem | Tag/Lyric Fix | Studio Fix |
|---------|---------------|------------|
| Outro ends abruptly | Keep last line short, add [Outro] | Add fade out on region |
| Tempo drift breaks DAW import | Keep arrangement focused, avoid over-tagging | Set Manual BPM, export Multitrack |
| Need clean loop for social | Write dedicated hook loop section | Export Selected Time Range |
| Need remix-ready session | Write clean section boundaries, limit instruments | Export Multitrack, optionally get MIDI |
| Chorus not strong enough | Shorten hook lines, add [Energy: High] before chorus | Copy best chorus to Final Chorus position |
| Verse too busy | Reduce instrument tags, keep 2-3 mids only | Delete or crop verbose sections |
| Transition too abrupt | Add transition cue in lyrics | Heal edit point, add crossfade |

## Studio Best Practices

### Design for Stems

If you plan to export stems:
- Keep palette focused (2-3 core instruments)
- Write clear section boundaries
- Avoid instrument sprawl
- Use consistent structure tags

### Plan Replace/Extend Outcomes

Most fix passes happen because:
- Chorus too wordy → Keep hook lines short (4-6 words)
- Bridge doesn't contrast → Strip drums, change chords
- Ending lands wrong → Keep outro short, plan fade

**Design these correctly in lyrics to need fewer Studio edits.**

### Section Boundaries Are Your Control Surface

Tags work best when the writing supports them:
- Chorus that reads like a chorus (short, repeatable hook)
- Bridge that reads like a bridge (contrast + space)
- Tags reinforce intent—they don't replace it

## Example: Complete Studio Workflow

**Goal:** Create a finished pop track with clean social media loop

### 1. Generate with Structure
```
[Mood: Confident]
[Energy: Medium]
[Instrument: Keys, Drums]

[Intro]
(short, establish palette)

[Verse]
Walking through the city lights
Everything feels right tonight

[Pre-Chorus]
[Build-Up]
Can you feel it rising now

[Chorus]
[Energy: High]
We're alive, we're on fire
Taking it higher and higher

[Bridge]
[Breakdown]
Let it breathe, let it break

[Final Chorus]
[Energy: High]
We're alive, we're on fire
Taking it higher and higher

[Outro]
(short fade)
```

### 2. Edit in Studio
- Chorus came out perfect → Copy to Final Chorus
- Verse slightly long → Crop by 2 bars
- Transition into bridge abrupt → Heal edit point

### 3. Add Fades
- Fade out on outro (3 seconds)
- Crossfade between verse and pre-chorus

### 4. Export Two Versions

**A. Full Song:**
- Set Manual BPM: 110
- Export Multitrack for DAW finishing

**B. Social Loop:**
- Select Chorus time range (0:45 - 1:10)
- Export Selected Time Range
- Clean 25-second loop for TikTok/Reels

## Key Principles

1. **Generate with Studio in mind** - Plan structure for easy editing
2. **Region editing > regeneration** - Fix specific sections, keep what works
3. **Fades are your friend** - Smooth transitions and endings
4. **Set Manual BPM for DAW export** - Prevents tempo drift
5. **Export strategy by goal** - Full Song / Loop / Stems
6. **Fewer instruments = cleaner stems** - Keep palette focused
7. **Top-load palette, localize energy** - Better generation = fewer edits
8. **Section boundaries are control** - Write clear structure in lyrics

---

**Remember:** Studio is for finishing, not fixing bad generations. Start with solid prompts and structure (see SUNO-AI-AGENT-GUIDE.md), then use Studio to polish and export professionally.
